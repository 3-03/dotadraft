# Dota Draft Helper — Telegram-бот

Пишешь боту вражеские пики — он подсказывает, кем их закрыть.
Подбор строится на **реальной статистике матчапов из OpenDota** (винрейты героев
друг против друга), а не на захардкоженном списке.

## Как работает

Для каждого вражеского героя бот берёт из OpenDota его винрейт против всех остальных
героев. Если против кандидата враг играет **хуже своего среднего** — значит кандидат
его контрит. Баллы суммируются по всему вражескому драфту, и сверху оказываются герои,
которые давят сразу нескольких.

## Установка (Windows, локально)

1. **Получи токен бота.** В Telegram напиши [@BotFather](https://t.me/BotFather),
   команда `/newbot`, придумай имя — он выдаст токен вида `123456789:AA...`.

2. **Настрой токен.** В папке проекта скопируй `.env.example` в `.env` и вставь токен:
   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

3. **Установи зависимости** (в PowerShell, из папки проекта):
   ```powershell
   pip install -r requirements.txt
   ```

4. **Запусти бота:**
   ```powershell
   python bot.py
   ```
   Оставь окно открытым — пока оно работает, бот отвечает. `Ctrl+C` — остановить.

## Использование

Весь подбор происходит **внутри Mini App** — бот сам в чате ничего не считает.
Открой чат с ботом: снизу появятся постоянные кнопки:

- **🎮 Открыть драфт-помощник** — запускает приложение с иконками героев;
- **ℹ️ Как пользоваться** и **👤 Автор** — короткие подсказки.

В приложении тапни по вражеским героям и нажми «Показать контр-пики» — появится
список героев, которые их контрят, со средним преимуществом и разбивкой по каждому врагу.

Команды: `/start`, `/help`, `/app`.

## Mini App — приложение с иконками героев

Вместо ввода текстом можно открыть встроенное приложение: сетка иконок всех героев,
тапаешь по вражеским пикам → внутри приложения появляется список контр-героев (тоже
с иконками, преимуществом и разбивкой по каждому врагу). Файл — `webapp/index.html`,
он **полностью статический** (сам тянет иконки и статистику из OpenDota).

Telegram требует, чтобы Mini App открывался по **HTTPS**. Самый простой бесплатный
способ — GitHub Pages:

1. Создай репозиторий на GitHub и залей в него содержимое папки `webapp/`
   (файл `index.html` должен лежать в корне репозитория или в папке `docs/`).
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**,
   выбери ветку и папку. GitHub выдаст ссылку вида
   `https://ТВОЙ_ЛОГИН.github.io/имя-репозитория/`.
3. Впиши эту ссылку в `.env`:
   ```
   WEBAPP_URL=https://ТВОЙ_ЛОГИН.github.io/имя-репозитория/
   ```
4. Перезапусти `python bot.py`. Появится кнопка меню «Драфт» слева от поля ввода,
   а команда `/app` пришлёт кнопку «Открыть драфт-помощник».

**Быстрый тест без хостинга** (открыть прямо в Telegram со своего ПК) — прокинь
локальную папку через туннель, например [cloudflared](https://github.com/cloudflare/cloudflared):
```powershell
python -m http.server 8000 --directory webapp
cloudflared tunnel --url http://localhost:8000
```
Скопируй выданный `https://…trycloudflare.com` в `WEBAPP_URL` и перезапусти бота.

> Приложение можно проверить и в обычном браузере — просто открой `webapp/index.html`.
> Оно работает и вне Telegram (только без нативной кнопки и тем оформления).

## Проверка без Telegram

Чтобы убедиться, что подбор работает (без токена и бота):

```powershell
python selftest.py
```

## Структура

| Файл | Назначение |
|------|-----------|
| `bot.py` | Точка входа, Telegram-хендлеры, подключение Mini App |
| `engine.py` | Разбор ввода и подсчёт преимущества по матчапам |
| `opendota.py` | Запросы к OpenDota API + файловый кэш (`cache/`) |
| `aliases.py` | Русские названия и сокращения героев (легко дополнять) |
| `webapp/index.html` | Mini App: сетка иконок героев + подбор контр-пиков |
| `selftest.py` | Офлайн-проверка движка |

## Настройка

- **Добавить свои сокращения героев** — правь `aliases.py` (ключ: как вводишь → значение:
  английское имя героя).
- **Порог достоверности / число рекомендаций** — константы `MIN_GAMES` и `TOP_N` в `engine.py`.
- **Время жизни кэша** — `HERO_TTL` и `MATCHUP_TTL` в `opendota.py`. Кэш лежит в `cache/`;
  чтобы обновить данные принудительно — удали файлы оттуда.

## Замечания

- OpenDota отдаёт **публичную выборку** матчапов, а не всю базу игр — по редким парам
  героев данных может не быть (в ответе помечается «нет данных»). Это не ошибка бота.
- Без API-ключа лимит OpenDota — порядка 2000 запросов в день; ответы кэшируются,
  так что для личного использования этого с запасом хватает.
- Совет учитывает только матчапы «герой против героя», без учёта твоего состава,
  ролей и синергии. Это подсказка для драфта, а не финальное решение.
